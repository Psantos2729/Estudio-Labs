# ¿Qué es un programa?

Un programa es una lista de instrucciones que la computadora sigue **en orden**, de arriba hacia abajo.

```python
print("Hola")
print("Adiós")
```

Primero imprime `Hola` y después `Adiós`. Si cambias el orden de las líneas, cambia el resultado.

## `print` muestra cosas en pantalla

Lo que va entre comillas es texto (en Python se llama `str`). Los números van sin comillas:

```python
print(3 + 4)    # imprime 7
print("3 + 4")  # imprime 3 + 4, porque es texto
```

## Antes de seguir

Pregúntate siempre: **¿qué va a imprimir esto?** Predecirlo antes de correrlo es la mejor forma de aprender.
