# pylab · Estudio-Labs

Plataforma para aprender Python desde cero y prepararse para los laboratorios de C5.
Cada módulo se desbloquea solo cuando dominas el anterior: examen con casos ocultos,
85% para aprobar y repasos a los 3, 7, 21 y 60 días.

## Empezar

```bash
npm install
npm run dev        # http://localhost:5173 (modo invitado si no hay .env.local)
```

Para guardar progreso, conecta Supabase siguiendo [docs/setup.md](docs/setup.md).
